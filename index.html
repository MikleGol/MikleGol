Simulation Content Engine

A privately operated application for running automated live game broadcasts with country flags, managing live stream sessions, and powering optional interactive game features.

What the application does

  • Creates and manages the operator's live broadcasts using the YouTube Data API.
  • Updates broadcast metadata, thumbnails, and stream-related settings when configured.
  • Reads live chat messages so viewers can participate in supported game interactions.
  • May post live chat replies when the operator explicitly enables that feature.
  • Uses Google OAuth authorization to connect only accounts whose owners approve access.

Who uses it?

The application is primarily a private operational tool used by its creator to run and monitor automated live broadcasts. It is not a general-purpose social platform or a service that asks viewers to sign in.

Why Google access is requested

Google authorization allows the application to perform the live broadcast and chat operations listed above on a connected account. Access is used for these functions, not for advertising, resale of personal information, or unrelated profiling.
